# HelloWps - WPS加载项项目

这是一个基于Vue 3和Vite的WPS加载项项目，提供了丰富的文档内容插入功能。

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

## 项目特性

- **内容插入功能**：支持插入表格、图片、标题、段落等
- **用户友好界面**：提供直观的操作界面和实时反馈
- **错误处理**：完善的错误处理和用户提示
- **响应式设计**：支持多种设备和屏幕尺寸

## 新增功能

### 内容插入工具
- 表格插入：支持自定义行数、列数、大小和位置
- 图片插入：支持本地和网络图片，可设置尺寸和环绕方式
- 标题插入：支持一级、二级、三级标题，自动应用样式
- 段落插入：支持自定义文本内容，自动应用正文样式
- 其他功能：分页符、页眉页脚、目录等

### 快速插入示例
- 示例文档：一键插入完整的示例文档结构
- 示例表格：插入预设的示例表格
- 文档结构：展示标题层级组织方式

## 使用方法

1. 在WPS中加载该加载项
2. 点击"内容插入"按钮打开任务窗格
3. 使用各种插入功能创建文档内容
